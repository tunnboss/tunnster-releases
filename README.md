# TUNNSTER

Клиент VPN для Windows 10/11 x64 с выбором приложений: выбранные используют VPN,
остальные — обычное подключение.

## Скачать

Откройте [релизы](https://github.com/tunnboss/tunnster-releases/releases) и скачайте
`TUNNSTER-Setup-<версия>.exe`. ZIP-файл нужен встроенному механизму обновления;
для обычной установки используйте EXE.

Для VPN-доступа нужны аккаунт и действующий промокод. Оплата и пробный период пока
отключены. Настройки соединения клиент получает автоматически после авторизации.

## Обновления

Начиная с dev.41 клиент проверяет наличие новых версий при запуске и каждые пять
минут. Обновления скачиваются с GitHub; клиент проверяет подпись манифеста и SHA-256
пакета. Установка не запускается во время активного подключения VPN. Windows может
запросить подтверждение администратора; настройки и данные аккаунта сохраняются.

Если установлена более старая версия без адреса обновлений, один раз установите
dev.41 или более новую вручную. После этого будущие релизы доступны из клиента.

## Статус

Сейчас публикуются сборки для тестирования. Установщик пока не имеет
Authenticode-подписи издателя: это отдельная подпись, не подпись пакета обновления.
Windows может показать предупреждение о неизвестном издателе.

## Компоненты

Используется [mihomo v1.19.30](https://github.com/MetaCubeX/mihomo/tree/v1.19.30)
по GPL-3.0 и WireGuard tools. Лицензии включены в поставку, исходники mihomo
приложены отдельным архивом; исходники WireGuard tools включены в установочный пакет.

Этот репозиторий содержит только релизы и метаданные обновлений, не исходный код
приложения, секреты серверов, пользовательские ключи или промокоды.
